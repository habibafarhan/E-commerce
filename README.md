# 🛒 E-Commerce Web Application

تطبيق متجر إلكتروني متكامل وتفاعلي تم بناؤه باستخدام **React** و **Vite** بتصميم عصري ومتجاوب بالكامل.

🌐 **رابط المعاينة المباشرة (Live Demo):**  
[https://habibafarhan.github.io/E-commerce/](https://habibafarhan.github.io/E-commerce/)

---

## 🌟 الميزات الأساسية (Key Features)

* 🔍 **بحث وتصفية في الوقت الفعلي (Real-time Search & Filtering):** إكانية البحث عن المنتجات وتصفيتها حسب التصنيفات بسلاسة.
* 🛍️ **إدارة السلة (Cart Management):** إضافة وحذف المنتجات وتعديل الكميات مع حساب الإجمالي تلقائياً.
* 💾 **حفظ البيانات (Data Persistence):** حفظ عناصر السلة في الـ `localStorage` لضمان عدم ضياعها عند إعادة تحميل الصفحة.
* 📱 **تصميم متجاوب بالكامل (Fully Responsive):** متوافق مع كافة أحجام الشاشات (الهواتف، الأجهزة اللوحية، والشاشات الكبيرة).
* ⚡ **أداء سريع وسلس (Fast Performance):** يعتمد على Vite لبناء سريع واستجابة عالية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Front-End:** React.js, JavaScript (ES6+)
* **Styling:** CSS3, Swiper.js (Sliders)
* **Routing:** React Router DOM
* **Build Tool:** Vite
* **Deployment:** GitHub Pages
